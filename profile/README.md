  <h1 itemprop="name">ТОП ЗАЙМ.RU — агрегатор микрозаймов с открытой аналитикой реестра ЦБ</h1>

  <p itemprop="description">
    Технологическая платформа, которая в реальном времени собирает, нормализует 
    и сравнивает условия микрозаймов от лицензированных МФО. Мы делаем рынок 
    прозрачным: автоматически валидируем офферы, исключаем скрытые платежи 
    и предоставляем публичный аналитический инструмент на основе 
    <a href="https://top-zaim.ru/reestr-mfo/" target="_blank" rel="noopener">реестра МФО Центрального Банка</a>.
  </p>

  <h2>📊 Аналитика реестра МФО</h2>
  <p>
    На странице <a href="https://top-zaim.ru/reestr-mfo/">reestr-mfo</a> мы публикуем 
    агрегированную статистику и фильтруемые данные из официального реестра ЦБ РФ. 
    Пользователи и разработчики могут в реальном времени отслеживать:
  </p>
  <ul>
    <li>📋 Количество действующих и исключённых микрофинансовых организаций;</li>
    <li>🔍 Распределение МФО по регионам и статусам лицензий;</li>
    <li>⏱ Динамику изменений в реестре за последние периоды;</li>
    <li>⚠️ Мгновенную проверку конкретной компании на предмет наличия лицензии.</li>
  </ul>
  <p>
    Аналитика строится на автоматической синхронизации с реестром ЦБ и обновляется 
    по мере публикации изменений. Данные доступны в человекочитаемом виде и через 
    API-эндпоинты (документация появится в этом репозитории).
  </p>

  <h2>⚙️ Ключевые возможности платформы</h2>
  <ul>
    <li>🔍 Умный поиск с ранжированием по реальной полной стоимости кредита (ПСК).</li>
    <li>🛡️ Автоматическая сверка офферов с реестром ЦБ — только проверенные МФО.</li>
    <li>📊 Динамический рейтинг займов, подкреплённый пользовательскими отзывами.</li>
    <li>⚡ Мгновенный подбор: от займов под 0% до долгосрочных продуктов.</li>
  </ul>

  <h2>🧱 Технический стек</h2>
  <p>
    Микросервисная архитектура на Go и TypeScript, асинхронная ETL-шина данных, 
    PostgreSQL + Redis для горячего кэша, CI/CD через GitHub Actions. 
    Фронтенд — SPA на React с SSR для максимальной производительности и SEO.
  </p>

  <h2>📂 О репозитории</h2>
  <p>
    Здесь вы найдёте вспомогательные компоненты платформы, внутренние библиотеки 
    для работы с финансовыми API, примеры антифрод-проверок и код для парсинга 
    и визуализации данных реестра МФО. Мы придерживаемся подхода docs-as-code 
    и публикуем ключевые архитектурные решения (ADR) прямо в репозитории.
  </p>
